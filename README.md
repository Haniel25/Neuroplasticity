# Neuroplasticité / Neuroplasticity — Haniel Dev

A bilingual (French / English), responsive static website about neuroplasticity, the hippocampus, synaptic plasticity, learning, memory, and neurological conditions.

## Project structure

```text
Neuroplasticity/
├── index.html          # French version
├── index-en.html       # English version
├── style.css           # Shared dark theme and responsive layout
├── README.md
└── images/
    ├── brain-neuroplasticity.png
    ├── hippocampus-circuit.svg
    └── synapse.svg
```

## Preview

1. Extract the ZIP archive.
2. Open the `Neuroplasticity` folder.
3. Double-click `index.html` to open the French version.
4. Use the **EN** link in the header to switch to English. In the English version, use **FR** to return to French.

No installation, database, framework, or build command is required. The website uses HTML and CSS. An internet connection is needed only for the optional Google Fonts; the content and local illustrations are stored in this folder.

## Edit the website

- Edit French content in `index.html`.
- Edit English content in `index-en.html`.
- Change colors and layout in `style.css`.
- Replace illustrations in `images/`, keeping the same filenames, or update the image paths in both HTML files.
